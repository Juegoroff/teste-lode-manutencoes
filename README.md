
Lode Manutenções
Sistema desenvolvido para teste técnico.
Tecnologias Utilizadas
Backend

- Java
- Spring Boot
- PostgreSQL
- JUnit
Frontend

- Vue.js 3
- JavaScript
- CSS
Funcionalidades

- Cadastro de equipamentos
- Listagem de equipamentos
- Atualização de equipamentos
- Remoção de equipamentos
- Busca de equipamentos por nome
- Identificação visual por status
Status dos Equipamentos

- Operacional
- Manutenção Necessária
- Crítico
Testes
Foram implementados testes unitários para:

- Validação de equipamento sem nome
- Alteração de status dos equipamentos
Como executar o backend

1. Configurar o PostgreSQL.
2. Criar o banco de dados lode.
3. Executar a aplicação Spring Boot.
Como executar o frontend

1. Acessar a pasta frontend.
2. Instalar as dependências:
npm install

1. Executar a aplicação:
npm run dev
